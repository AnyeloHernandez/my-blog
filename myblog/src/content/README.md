# Formato para guardar los archivos

Cada archivo debe tener el siguiente formato:

```markdown
---
title: Mi primer post!
date: 2026-05-08
autor: Anyelo Hernández
summary: Breve descripción del contenido del post. Hola mundo!
tags: [introducción, hola mundo]
---

# Mi primer post!
```

El archivo debe guardarse con el nombre `post-title.md`, donde `post-title` es una versión en minúsculas y sin espacios del título del post. Por ejemplo, si el título es "Mi Primer Post", el archivo se llamaría `mi-primer-post.md`.
